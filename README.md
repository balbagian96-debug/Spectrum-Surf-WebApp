# Spectrum Surf (web)

Pixel-art beach web app about the electromagnetic spectrum, from radio waves to gamma rays.
Surf the spectrum, read each wave's causes and effects, run the Quiz Run game, and meet the team.

Made by: Grade 10 CT - Joy Committee.

Plain static site, no build step: `index.html` plus `assets/` (images, fonts, music, sounds).
Run locally with `python3 -m http.server` and open http://localhost:8000.
Deploys to Vercel as-is (Framework preset: Other, no build command, output directory = root).
